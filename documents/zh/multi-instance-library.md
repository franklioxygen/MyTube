# 多实例媒体库

把几台 MyTube 服务器连起来，在其中一台上浏览并播放所有服务器的视频。比如视频分别存在 NAS 和台式机上，你在平时常用的那台上就能看到两边的视频。

这里有两种角色，同一台服务器可以同时兼任两种：

- **分享方**：签发访问密钥，让别的服务器读取自己的媒体库。
- **观看方**：用这把密钥连接分享方，同步对方的媒体库，并经由自己播放对方的视频。

在你签发密钥并用它连接之前，什么都不会被分享出去。

## 前提条件

- 两台服务器都运行包含此功能的 MyTube 版本。
- 观看方能通过网络访问分享方。请求是服务器之间直接发的，不经过你的浏览器。
- 你在两台上都是所有者：管理员，或者未开启登录。

## 设置步骤

### 1. 签发访问密钥（在分享方）

打开 **设置 → 集成与高级 → 多实例媒体库 → 供其他实例访问**，点 **签发访问密钥**：

| 选项 | 含义 |
|---|---|
| 备注名 | 方便你认出这把密钥，比如"客厅"。 |
| 权限 | **浏览媒体库** 会列出视频；**播放媒体** 还允许播放。不勾播放媒体的话，视频能看到但播放不了。 |
| 隐藏视频 | **仅可见视频** 只分享访客也能看到的视频；**包含隐藏视频** 连隐藏的也分享。 |
| 有效期 | 可选，到期后密钥失效。 |

密钥**只显示这一次**，请马上复制。每把密钥只能给一个观看方用：第一个用它的实例会绑定这把密钥。

### 2. 连接（在观看方）

打开 **设置 → 集成与高级 → 多实例媒体库 → 已连接的实例**，点 **连接实例**：

| 字段 | 填写什么 |
|---|---|
| 名称 | 这台实例在你的媒体库里显示的名字。 |
| 地址 | 你在浏览器里打开对方 MyTube 用的地址。双容器 Docker 部署一般是 `http://<主机>:5556`，单容器部署是 `http://<主机>:5551`。 |
| 访问密钥 | 第 1 步复制的密钥。 |

局域网地址可以用 `http`，公网地址必须用 `https`。

### 3. 开始观看

连接后会马上同步一次，之后大约每分钟同步一次；点 **立即同步** 会立刻同步一次。对方的视频会出现在首页，以及搜索、作者和标签页面里，并标出来自哪台实例，可以播放、拖动进度和显示字幕。

## 目前能做什么

| 已支持 | 暂不支持 |
|---|---|
| 浏览、搜索、标签、作者 | 访客看到远端视频（远端视频只对所有者可见） |
| 播放、拖动进度、字幕 | 把远端视频加入收藏夹或收藏 |
| 对方离线时显示提示 | 在本机记录播放进度和播放次数（续播位置只保存在你当前的设备上） |
| 约每分钟自动同步 | 编辑、评分、加标签、删除远端视频（请在它所在的实例上操作） |

批量操作、管理页面、统计和最高评分都只针对本机自己的数据，所以不包含远端视频。

## 状态说明

| 状态 | 含义 | 怎么处理 |
|---|---|---|
| 等待同步 | 刚连接、刚重新启用，或刚更换了密钥 | 等第一次同步完成，或点 **立即同步** |
| 已同步 | 已是最新 | — |
| 同步失败 | 上次同步失败（对方离线、超时），仍显示上次同步到的视频 | 确认对方在运行并且能访问到 |
| 访问密钥被拒绝 | 对方吊销、更换或暂停了这把密钥，或者密钥已过期 | 在对方重新签发一把，然后在这里点 **更换访问密钥** |
| 访问密钥不可用 | 本机读不出保存的密钥了（见下文"备份与恢复"） | 找回密钥文件，或者更换访问密钥 |
| 该地址上是另一个实例 | 这个地址上现在是另一台 MyTube | 检查地址；如果确实换了实例，移除后重新连接 |
| 需要更新 | 对方运行的版本不兼容 | 两台都更新到最新版本 |

## 管理密钥和连接

在分享方，每把密钥都会显示是哪台实例在用、最近一次使用的时间：

- **更换密钥**：生成新密钥，旧的立即失效。把新密钥填到观看方。
- **吊销**：密钥立即失效，正在用它的播放也会中断。
- **删除**：彻底删掉这把密钥。
- **恢复**：重新启用被数据库恢复暂停的密钥。

在观看方：

- 关掉某个连接的 **启用** 开关，它的视频会立刻隐藏。
- **移除** 只删掉本机同步来的条目，不会删除对方的任何东西。

## 网络与安全

- 只有当地址解析到的全是内网地址时，才允许用 `http`。之后每次连接都会重新检查：如果这个域名后来指向了公网地址，连接会被拒绝。连这类实例时一律直连，不走代理。
- 分享方只保存密钥的哈希值。每次请求都会重新检查可见性，所以把视频设为隐藏会立即生效。
- 观看方用 `data/federation.key`（如果设置了 `MYTUBE_FEDERATION_KEY` 环境变量，就用它）加密保存密钥。对方的地址和存储链接都不会出现在你的浏览器里。
- 项目自带的 Nginx 配置对 `/api/federation/media` 和 `/api/federation/v1` 关闭了缓冲。如果你用自己的反向代理，也要这样配置，否则拖动进度会出问题。

## 备份与恢复

- 备份数据库时一并备份 `data/federation.key`。没有它，已连接的实例会显示"访问密钥不可用"，只能逐个更换访问密钥。
- 恢复或导入数据库后，本机签发出去的所有密钥都会被暂停，本机建立的所有连接都会被停用。确认没问题后，再恢复或更换密钥，并重新启用这些连接。
- 如果你复制了一份部署，而且两份都要继续运行，请在复制出来的那份上点 **重置身份**。它会得到新的实例 ID，继承来的密钥都会被吊销。
