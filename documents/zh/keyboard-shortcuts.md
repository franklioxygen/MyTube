# 键盘快捷键

播放器采用与 YouTube 一致的按键，肌肉记忆可以直接沿用。只要播放页处于焦点状态快捷键就生效，不需要先点一下视频。

## 播放控制

| 按键 | 作用 |
|---|---|
| `Space` 或 `K` | 播放 / 暂停 |
| `←` / `→` | 按短跳转后退 / 前进 |
| `J` / `L` | 按中跳转后退 / 前进 |
| `0`–`9` | 跳到视频的 0%–90% 处 |
| `Home` / `End` | 跳到开头 / 结尾 |
| `,` / `.` | 后退 / 前进一帧（会先暂停） |
| `<` / `>` | 减速 / 加速 |

跳转幅度取的是你自己的设置，不是固定值：在 **设置 → 播放器默认设置** 里可以改「短跳转」和「中跳转」（默认 10 秒和 60 秒）。逐帧按 30fps 估算——HTML 视频不提供帧率，所以这个步长是近似的。

倍速在速度菜单提供的那一组档位间移动（0.5、0.75、1、1.25、1.5、2、3），而不是任意倍数，这样键盘和菜单不会给出不一致的结果。

## 音量

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 音量增加 / 降低 5% |
| `M` | 静音 / 取消静音 |

取消静音恢复的是静音前的音量，不是最大音量。

## 画面

| 按键 | 作用 |
|---|---|
| `F` | 全屏开 / 关 |
| `T` | 影院模式开 / 关 |
| `C` | 字幕开 / 关 |

按 `T` 进入影院模式时会退出全屏——两者都是把播放器变大的方式，同时处于两种状态就没有可以切回去的入口了。

`C` 没有菜单可选，所以它要么关掉全部字幕，要么打开第一条可用轨道：优先文件字幕，没有文件字幕时用实时翻译字幕。

## 接下来播放

| 按键 | 作用 |
|---|---|
| `Shift` + `N` | 播放下一个视频 |
| `Shift` + `P` | 播放上一个视频 |

`Shift+N` 跳到「接下来播放」侧栏的第一项——也就是自动连播会播的那个视频。

`Shift+P` 只有在从合集或播放队列进入这个视频时才有目标，这和 YouTube 一致：「上一个」是播放列表内的动作。单独打开一个视频时这个键不做任何事。

## 什么情况下不触发

以下三种情况快捷键会让开：

- **正在输入。** 输入框、多行文本框、下拉框和富文本区域拿着键盘时不触发，页面自己的弹窗里的输入框同样如此。
- **弹窗或菜单打开着。** 字幕、倍速、合集这些菜单打开期间由它们接管键盘。
- **按住了修饰键。** 带 `Ctrl`、`Cmd`、`Alt` 的组合属于浏览器——`Cmd+←` 仍然是后退，`Ctrl+F` 仍然是查找。`Shift` 例外，上面的快捷键要用到它。

长按不会连发：每按一次只触发一次。

## 浏览

| 按键 | 作用 |
|---|---|
| `←` / `→` | 分页网格的上一页 / 下一页 |

在首页和合集页生效，规则相同——输入时不触发，弹窗或菜单打开时也不触发。

## 不适用的范围

**D 模式**（标准播放器无法处理的源所使用的兼容播放器）有自己的一套控件，不接受上述快捷键。
